What was found
The vendor SDK drops a batch when the API answers 429 and never retries it. About 0.4% of events since the March upgrade, all on large tenants.
Why change course
The goal was to know why. Knowing is done, and the fix is one retry policy plus a replay of what was lost. A separate goal would repeat this context.
